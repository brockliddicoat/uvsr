# fonts

- [ProggyClean](proggy-clean/ProggyClean.ttf) and
  [ProggyForever Regular](proggy-forever/ProggyForever-Regular.ttf) are retained
  source assets with complete adjacent MIT notices. the
  [legal record](../../legal/imgui-fonts.md) owns their source pins, hashes,
  default-font relationship, and redistribution terms.
- [Segoe UI](segoe-ui/README.md) holds local Windows font copies excluded from
  Git. its [legal record](../../legal/segoe-ui.md) records the restrictions.

the framework has no font loader or packaging rule yet. retaining these assets
does not select a runtime font or add an ImGui dependency.
