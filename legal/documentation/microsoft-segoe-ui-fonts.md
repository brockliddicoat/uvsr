# Microsoft Segoe UI Fonts

## Record

- Owner: Microsoft Corporation.
- Source: the developer's Windows-installed Segoe UI fonts.
- Local files: `segoeui.ttf`, `seguisb.ttf`, and `segoeuib.ttf` in
  [`assets/fonts/segoe-ui`](../../assets/fonts/segoe-ui/README.md).
- Governing terms: the applicable Microsoft product license and the notices
  embedded in the original font files.
- Distribution status: no separate redistribution license is recorded. font
  binaries are ignored by Git and excluded from repository distribution.

## Scope of Use

Microsoft permits Windows applications to use installed system fonts to render
content. its published FAQ states that Windows font files generally cannot be
redistributed, copied to other computers or servers, modified, or converted.
document embedding rights do not authorize embedding fonts in games or apps.
the FAQ identifies separate licensing as an option for Segoe UI.

source: [Microsoft Font Redistribution FAQ](https://learn.microsoft.com/en-us/typography/fonts/font-faq),
reviewed 2026-09-18. preserve the original font bytes and embedded notices.
