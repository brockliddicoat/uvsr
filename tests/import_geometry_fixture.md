# geometry control data

the geometry test combines the old common and native-import suites. all nine importer comparisons now run in `uvsr_import_geometry_tests`, along with the original 96 matrix cases, six tangent cases, 113 rejections, allocation retries and 100,000-node deep/wide checks. the duplicate executable and its conditional control path are removed.

`import_geometry_math_fixture.h` contains the original matrix inputs and exact decomposed transforms, plus the six tangent results. [the independent capture](C:/Users/brock/OneDrive/Documents/uvsr/work/donut-factor-out-v4/runs/20260909-01/09-geometry-fixtures-v1/reference-02/receipt.json) calls only the original Donut math helpers for these results. the header changes only the capture's line endings. it preserves the singular matrix case and the explicit zero expectation for degenerate tangents.

`import_geometry_fixture.bin` has 18,974 bytes and SHA-256 `b8b75d99878f200654fb6996b8699bd43ce8446016a8c31ec6122093647bcd73`. its writer independently loads each original JSON/buffer input through Donut's `GltfImporter`; its candidate scene/geometry parameters are unused. the capture driver also runs the original native-owner tests, but their results are not written as expected data. two captures match exactly. [source and library provenance](C:/Users/brock/OneDrive/Documents/uvsr/work/donut-factor-out-v4/runs/20260909-01/09-geometry-fixtures-v1/reference-02/input-provenance.json) preserves the actual consumed inputs and compiled controls. the Donut revision is `bc1ea24b0486f1c00d89327fe16c0b4dd11c5937`, with retained patches and MSVC x64 Release, static CRT, C++17, `/O2 /fp:precise /EHs-c-`.

the binary starts with `UVIG0001` and a 32-bit case count of nine. each case contains its original JSON/buffer spans, node/mesh/instance counts, then the compared node, instance, joint, mesh, primitive and attribute records in the original traversal order. counts, indices and flags are little-endian 32-bit integers; matrices retain their original float/double fields. spans store a 32-bit byte count followed by exactly those bytes. node names, parents, authored flags and world transforms precede instance/joint records. mesh ranges, deformation flags and bounds precede primitive ranges/bounds, then each present buffer's compared attributes. attribute records retain the original presence flag, byte offset and byte count. `UVIGEND1` ends the file, with no trailing bytes.

the reader preserves exact index, attribute and inverse-bind bytes, scalar transform/bounds equality, registration order, deformation flags and conditional range checks. only authored skin-prototype joint/weight ranges are compared; the old loader's uninitialized static lanes remain excluded. the original native-owner tests still require those unused candidate lanes to be initialized.

CTest sets this directory as the working directory. direct execution needs the binary fixture there. the reader uses fixed 256-byte scratch and checks input identity, field lengths, case coverage and EOF. these are finite CPU controls, not GPU skinning, animation playback or universal importer equivalence.
