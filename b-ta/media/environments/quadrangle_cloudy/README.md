# Quadrangle Cloudy Environment

`quadrangle_cloudy_1k.hdr` is the 1K Radiance HDR version of
[Quadrangle Cloudy](https://polyhaven.com/a/quadrangle_cloudy) by
Savva Zakharov, downloaded from Poly Haven.

The asset is released under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
Poly Haven attribution is not required, but is included here to preserve clear
provenance.

The downloaded file is 1,671,356 bytes and has MD5
`705339eebceee57b9f32e2d44a05f1c7`, matching Poly Haven's published file
metadata.

UVSR uses this cloudy, low-contrast courtyard environment because it contains
broad directional variation without a hard solar disk. The directional light
and its shadow visibility remain the only source of hard sunlight.
