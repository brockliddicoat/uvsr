# AGFX behavior and future Rust changes

this is the ongoing record of inherited behavior worth revisiting for efficiency or simpler Rust. source pin: AGFX `f91b108a111d2ca3ca4b6586b6cb5dd750064fd7`, with inspected files frozen in the [source manifest](../tests/parity/primary-slice-sources.json). the [slice mapping](../tests/parity/primary-slice.md) owns required parity and oracles.

as of [E-029](execution.md#e-029-2026-09-19-executed-the-ordinary-rust-compute-slice), `crates/agfx/src/vulkan.rs` and its compute child own the bounded buffer/compute slice. the table distinguishes retained behavior, deliberate Rust changes and unimplemented candidates. no performance optimization has been measured. preserve source-visible behavior where required, but do not copy unsafe interfaces or cross-backend restrictions merely for line-by-line similarity.
